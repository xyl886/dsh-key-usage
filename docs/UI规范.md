# 界面规范（向内嵌宿主看齐）

本文件是 `dsh-key-usage` 面板的视觉与尺寸基准。**新增/修改样式前先读这里**；数值来自对宿主页面（「插件」「自动化任务」）的计算样式实测，不是手挑的。

## 1. 刻度表（`scripts/ui-scale.json`）

| 类别 | 允许值 |
| --- | --- |
| 间距（padding / margin / gap） | 0 1 2 3 4 6 8 10 12 14 16 20 24 28 32 36 40 48 |
| 圆角 | 0 1 2 3 4 6 8 9 10 12 14 16 20 999 |
| 字号 | 12 13 14 15 16 18 20 24 |
| 最小高度 | 20 24 28 32 36 40 44 |

`npm run check:ui`（已挂进 `npm run verify`）会扫 `src/client/styles/*.css`，出现刻度外的 px 值直接失败并给出文件与行号。要加新数值，先改刻度表并在这里说明理由，不要就地写。

不检查的项：`calc() / var() / max() / %`（视为使用令牌）、负 margin（吸顶与对齐的刻意写法）、`height`（图表条会用到 3–9px）、颜色（颜色只走 `--dsw-alias-*`，由 `check:tokens` 管）。

## 2. 与宿主对齐的基线值

| 项 | 值 | 说明 |
| --- | --- | --- |
| 页面外壳 | `padding: 28px 48px 48px` | 宿主单层内边距，顶部 28 / 水平 48 |
| 内容列 | `max-width: 960px` 居中 | 标题与区块一起居中，不再左贴 |
| 页面标题 | `20px / 500 / line-height 28px / letter-spacing normal` | 宿主实测值 |
| 分区标题 | `14px / 500 / line-height 22px`，主文字色 | 只当锚点，不与页面标题抢视线 |
| 正文 | `14px / line-height 22px` | |
| 辅助文字 | `13px`，`--dsw-alias-label-secondary` / `-tertiary` | 两档灰 |
| 控件高度 | `36px`（下拉、按钮、图标按钮、日期触发条、分段项 28px） | `--ku-control` |
| 控件圆角 | 输入 / 下拉 / 按钮 `12px`；分段选中药丸 `14px` | |
| 分段控件 | 容器无底色、无内边距；选中项底色 `--dsw-alias-interactive-bg-active`、无阴影、字重 400 | 宿主没有「灰底槽 + 白底浮起」那套语言 |
| 卡片 / 面板 | 圆角 9–12px、发丝边框、透明或 layer-2 底 | 宿主列表页无卡片容器，我们的数据面板保留轻边框，不做纯扁平分栏 |
| 区块间距 | 32px；卡片行距 8px | |

## 3. 字体与数字

- 数字统一 `font-variant-numeric: tabular-nums`。
- 金额两位小数、日均一位小数；千分位跟随全局格式化函数，不在组件里另写。
- KPI 数字 20px / 600；正文里的数字不单独放大。

## 4. 颜色

- 只使用宿主 `--dsw-alias-*` 令牌，`npm run check:tokens` 会校验每个令牌在宿主里真实声明过。
- 语义色：涨用 `state-error-primary`、跌用 `state-success-primary`（中文语境红涨绿跌），估算额不加语义色。

## 5. 布局约束

- 工具栏吸顶：`.stickyHead` 贴在页面滚动容器上（宿主 `div.*_page`），`margin` 用负值与页面内边距抵消。
- 浮层（筛选下拉、日历）用 `position: fixed` + 视口坐标，避免撑宽页面或坐标被相对定位叠加。
- 表格数字右对齐、首列左对齐；超长文本用省略号而不是换行把行撑高。

## 6. 例外与已知未对齐

- **主按钮**：宿主主按钮是实心深色（`#0f1115 + 白字`），我们是 ghost 描边。原因：深色写死会在深色主题下失效，等宿主提供实心按钮令牌后再改。
- **卡片圆角 20 / 无边框**：宿主「插件」页列表行是透明无边框容器；我们的数据面板需要分组感，保留发丝边框，圆角取 9–12。
- **表格**：宿主这两页没有表格，表头/行高按我们自己的可读性定（14px、行分隔 1px）。
