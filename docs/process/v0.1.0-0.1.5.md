# v0.1.0 ～ 0.1.5 过程留档（要点）

只记结论，细节看当批提交。

## 入口与骨架
- 入口从 `settings.section`（太挤）→ `sidebar.footer.action`（只能弹浮层）→ 最终 **`sidebar.panellist` + `main` 配对**：侧边栏导航项 + 主区域整页。
- 页面按 Tab 拆成 `tabs/*`，外壳 `KeyUsageSection` 只管路由与取数；样式按 `*.module.css` 分文件（basename 必须全局唯一）。

## 数据与口径
- 台账（天 × 通道 × 模型）负责总览 / 使用明细 / 热力图；会话事件负责项目 / 会话 / 单日按小时，两套按天取舍不相加。
- 余额与订阅窗口改为**自带快照**：宿主 `provider-snapshots.json` 实测停在 2026-09-30，不能当数据源。
- 价目分层演进：TS 硬编码 → 随包 `pricing-catalog.yml` → 再加 LiteLLM 聚合价（USD）→ 固定为四层，谁都不许猜价格。

## 交互
- 会话列表：搜索 / 通道 / 天数 / 排序 / 归档筛选；点行开详情抽屉，行内可展开模型构成。
- 「使用明细」支持自定义日期范围与 CSV / JSON 导出。
