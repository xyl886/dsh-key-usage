### A.2 风险（按等级）

| 等级 | 问题 | 处理 |
| --- | --- | --- |
| HIGH | **OpenRouter `/credits` 官方要求 Management Key**，DSH 的 openrouter 通道用普通推理 key → 会拿到 403 `Only management keys can perform this operation` | 403 单独出文案「需要管理密钥」；或改用普通 key 可用的 `GET /api/v1/key`（带 `limit/limit_remaining/usage_*`） |
| HIGH | **zai 余额端点零官方依据**；DSH 的 zai baseURL 是 coding 端点，coding key 受场景限制（错误码 1315） | 保留但标「未文档化、可能失效」；失败时给控制台链接；将来改用 429 业务码里的 `{next_flush_time}` 做窗口估计 |
| HIGH | **opencode-go `/zen/go/v1/usage` 官方文档中不存在**（文档已改 `/inference/`，DSH 包内 baseURL 仍是 `/zen/`） | 标注「未文档化、社区逆向」；404/HTML 静默降级；结构断言不写死；请求补 `x-opencode-session` 头 |
| MED | DeepSeek **不保证有 CNY 项**；`balance_infos` 可能为空 | 已有「优先 CNY → 取第一项」；把实际币种透传到界面，禁止把 USD 当 CNY 渲染；空数组 → 「无余额信息」 |
| MED | Moonshot 成功判定不能只看 `code`；国内外站账号 / Key 完全隔离（混用 401）；余额单位是人民币元 | 判定改看 `status === true && data`；401 文案提示「Key 与站点不匹配」；币种按 baseURL 判定 |
| MED | OpenRouter credits = 累计购买 − 累计使用，**不等于可用额度**；官方写明 **200 也可能带 error 体** | UI 不要当成「还能烧多少」；解析先查 `error` 字段 |
| MED | 「窗口」语义三家不同（OpenCode 5h = 月额度 20%、Z.ai 只在错误消息里给重置时间、OpenRouter 用 ISO8601） | 保持 per-scheme 适配器，时间解析分别实现，失败显示原文 |
| LOW | 轮询风暴：DeepSeek 不承诺 `Retry-After`；Kimi 风控限速「一旦触发即无法解除」 | 余额轮询保持 60 s 缓存 + 失败不立即重试（可加退避） |

> 一条**已核实的误报**：调研初稿推测「OpenRouter 会拼成 `/api/v1/api/v1/credits`」不成立 —— `balanceScheme` 用 `new URL(path, baseURL)`，以 `/` 开头的 path 只保留 origin。`test/live-quota.test.mjs` 断言各 scheme 在真实 baseURL 下的最终绝对 URL。

### A.4 定价口径

各厂商的逐条单价、来源 URL 与抓取日期以**随包价目文件 [`data/pricing-catalog.yml`](../pricing-catalog.yml) 为准**（每条带 `source` + `fetchedAt`，2026-10-13 对官方文档逐条复核；`test/fixtures/pricing-catalog.golden.json` 是逐条等值基线）。三条容易踩的口径：

- **DeepSeek 取中文文档的 CNY 价**，高峰 = 北京时间**周一至周五** 9:00–12:00 与 14:00–18:00，其余（含周末全天）空闲、半价；官方在售模型名是 `deepseek-flash`（`deepseek-v4-flash` / `…-vision-exp` 是已下线旧名，仍按 Flash 价计费）；
- **Kimi K2 系列官方表没有「缓存写入」列** → 该档留空，不按输入价顶替；**GLM 的 `Cached Input Storage` 官方标限免** → 记 0（文档明确给出的 0）；
- **OpenRouter 的价是 USD / token 字符串**，需 ×1e6 换算；`overrides` 阶梯价与 1 小时缓存写入档本插件的价格模型表达不了，未收录，只在 `note` 标注。

**不得推断冒充事实**：DeepSeek 未单列「缓存写入」价，内置价目按未命中价记录 —— 这是**口径推断**、已写进该条 `note`；`deepseek-v4.1-flash` 只存在于 OpenRouter，是**中转价**，与 DeepSeek 直连价各自独立收录、互不顶替；MiniMax 与 Qwen 本轮未收录。
