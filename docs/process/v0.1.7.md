# v0.1.7 过程留档（文案极简化 · i18n · 目录重排；已随 0.1.7 发布）

只记结论，细节看当批提交。发布后继续做的改动记在 [`v0.1.8.md`](./v0.1.8.md)。

## 文案与 i18n
- 中文硬编码字面量 289 → **1**（仅 Dialog 兜底默认值）；**135 处 JSX 裸文本**（`>调用<` 这类，之前扫描没覆盖）全部入词典。
- i18n 按宿主契约接：`ctx.locale.register('dsh-key-usage', { zh, en })` + `bind` + `subscribe`，组件 `useT()` 即时重渲染；语言只跟宿主设置，插件不加开关；零依赖（`core/copy.ts` + `core/i18n.ts`）。
- 踩坑三条：模块级 `t()` 会在字典注册前求值（改 `labelKey`，导出/下拉项渲染时取词）；映射表要存**键**不能存取词结果；压缩时不能删口径（「聚合价目（美元）」被测试挡下）。
- 规则：界面标签中文 ≤6 字、提示 ≤8 字、英文 ≤2 词；解释性内容一律进口径弹窗或 tooltip。

## UI 与结构
- 新增原语层：`Button` / `Select`（自建 listbox）/ `Dialog`（口径弹窗）/ `EmptyState` / `tableScroll`（7 张宽表可横滚）；原生 `<select>` 清零。
- 颜色全部走真实宿主令牌；热力图色阶与通道调色板令牌化。
- 目录按域重排：`src/server/{data,pricing,quota,snapshot}`、`src/client/core`；`pricing-catalog.yml` 入 `data/`，`CHANGELOG` 入 `docs/`；过程文档按版本分卷（本目录）。
- 产物契约未动：`main: lib/index.js`、`client/client.js`、`exports` 三项仍指向原位置。

## 服务端中文 prose（第二批已完成的部分）

- 服务端固定中文串走 `core/serverText.ts` 映射（价目依据、会话服务降级原因），未收录的原样返回。
