## 与 0.1.7 的边界怎么定的

把 npm 上的 `0.1.7` 拉下来（`npm pack dsh-key-usage@0.1.7`），用包里的 `client/client.js`、
`lib/routes.js`、`README.md` 三个文件的 **git blob** 在历史里比对，三个都命中提交 `d84ea68`
（发布前那笔「补 0.1.7 变更记录」）—— 所以 0.1.7 的代码状态就是 `d84ea68`，之后的提交才是 0.1.8 的内容。
以后再要划边界，用同一手法（blob 比对）而不是看提交时间。

## 本版做了什么

- **系统日志落盘**：`src/server/data/log-file.ts` → `$DSH_HOME/dsh-key-usage/plugin.log`（JSONL、追加、超 512 KB 只留后半段、写目标双重校验）；端点 15 → **17**（新增 `GET|POST /dsh-key-usage/log`）。刷新页面后仍能查上次为什么失败。
- **失败原因只进日志**：页面上只剩一行「结论 · 查看系统日志」（`components/LogHint.tsx` + `requestOpenLog()`）；日志窗支持刷新 / 复制 / 导出 `.txt` / 清空、条目展开详情、失败条目重试。
- **会话名与子代理判定改走宿主投影**：名字取 `storages/session_projcache/sessions/<id>.json` 的 `record.rows.title.val`，按 id 惰性读 + mtime 缓存（首次全量约 331 ms，之后每次只 stat 约 16 ms）；子代理只有 `record.rows.subagent.val.identity` 存在才算（续接会话不再被误藏）。实测 4 个会话改判主会话，默认视图可见数与侧边栏一致。
- **项目 = 宿主工作区**：行骨架改用工作区表（名字用 `title`），不在表里的历史目录合并成一行「未归入工作区」（本机 9 行 → 5 行）；`ProjectRow` 增加 `workspaceTitle` / `paths` / `registered`。
- **界面去重**：删「另有 N 个子代理 / 已归档会话未显示」两行、「跨 N 天」、通道详情 7 处重复表达；占比条不再单列明细（悬停外侧弹一个 tip）。
- **自定义范围改日历弹层**（新增 `components/ui/DateRangePicker.tsx`）。
- **英文残留中文（第二批）**：服务端下发的 `costLabel` / `windowLabel` 改走词典键；三页计数、会话抽屉、通道详情、口径弹窗长句入词典。
- **测试**：新增 `test/log-file.test.mjs`（10 项）、`test/client-log.test.mjs`（9 项），`routes` / `session-meta` 扩充；测试文件 15 → 17。
- **工程**：修掉 publish 工作流的「假成功」（`dry_run` 传字符串时两个分支都不执行却报 success）。
- **文档**：`docs/` 根目录去掉序号编排（`01-架构与数据契约.md` → `架构与数据契约.md`、`06-开发与构建.md` → `开发与构建.md`），`04-归档会话的影响与对策.md` 的结论并入契约 §3.11 与 AGENTS 硬约束后移除；清掉两条指向已删文档的失效链接。
