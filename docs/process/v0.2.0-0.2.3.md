# v0.2.0 – v0.2.3（2026-10-29 ~ 2026-10-30）

这一卷覆盖「七页重排 + 全局筛选打通 + 分时口径」三个阶段，发布版本 0.2.0 / 0.2.1 / 0.2.2 / 0.2.3。

## 一、页面结构

- **7 个页面**：额度 / 概览 / 明细 / 分布 / 会话 / 工具 / 提问（原「额度与订阅 / 使用明细 / 工具与技能 / 提问词云」改名；「项目用量 + 按模型」合并为「分布」）。
- **顶部工具栏四行**：标题 + 动作（刷新周期 / 设置 / GitHub / 刷新，刷新在最右）→ 时间（范围分段 + 日期胶囊）→ 三维筛选（通道 / 项目 / 模型）→ 区块导航 + 导出 + 分页开关。整块吸顶。
- **页面区块不再带小标题**：靠 32px 区块间距与分隔线区分。

## 二、筛选成为全局输入

原则：**顶部筛选决定每个页面看到什么**。落地过程：

1. 概览 KPI 在筛选激活时改由过滤后的 `/usage` 重算（不再读 `summary` 月列，它没有通道 / 项目 / 模型维度）；
2. 会话页接时间范围（按会话首末时间与窗口求交）与通道；
3. 分布页接通道（模型行按 provider 收窄）；
4. 额度页跟通道（只显示选中通道的卡片）；
5. 工具页接范围 + 项目 + 模型（新增 `GET /tools`，折叠时按会话保留工具统计、窗口按天切片，索引缺失回 `null` 回落快照）；
6. 提问页接四维（新增 `GET /prompts`，复用按天词桶，上期取同长度前段）。

端点总数 17 → 19（16 只读 GET + 3 写 POST）。

## 三、分时与粒度

- `/usage` 新增 **`hoursByDate`**：窗口内每天 24 小时桶，含 calls / tokens / 输出 / 缓存读 / 会话数 / 成本（成本按该小时逐模型套两层价目，错峰按星期几 + 小时）；窗口超过 120 天不下发。
- 概览·使用趋势：**今天 24 根小时柱、7 天 28 根 6 小时桶**，其余按天，「全部」仍是年热力图；脚注与悬停标签跟着粒度走。
- 明细·分时成本：同样粒度，四档指标（费用 / Token / 输出 Token / 会话）；按天范围下「会话」档由会话行折算。
- 概览·按时段：补 `hourlyMetrics`（calls / tokens / sessions / cost），标题标「长期」——它是长期画像，不随范围切片。

## 四、概览 KPI 重做

十张卡、5×2：成本 / Tokens / 输入 / 输出 / 缓存读 / 命中率 / 日均 Tokens / 日均成本 / 调用次数 / 会话数。结构统一为「图标 + 标签 → 上期与环比同一行 → 大数」；环比取上一等长窗口并套同一组筛选；成本类上涨警示、下降安全；命中率用 `pp`。会话数修复了「概览没取会话段 → 恒为 —」的问题（概览可见时懒加载会话段）。

## 五、界面与工程

- **向宿主看齐**：标题 20/500、外壳 28/48 单层、内容列 960 居中、分段控件统一「无底槽 + 28 药丸 + 400」、控件 36 高 12 圆角、辅助文字 13。新增 `scripts/check-ui-scale.mjs` + `ui-scale.json`（刻度越界与「状态类漏挂基础类」都会让 `verify` 失败）。
- **存储 schema 3**：新增 `app_meta(scope, key, value, version, source, updated_at)`，`meta` / `litellm_meta` 打开库时迁移进来（旧表双写一轮）；价目元信息补 `bytes / sha256 / fetchedAt / upstream`；`fx_rate` 保持强类型独立表；i18n 仍走 `copy.ts`（不进库）。
- **发布**：0.2.0（CI 撞版本号未发）→ 0.2.1 → 0.2.2 → 0.2.3，全部走 `publish.yml`（带 provenance）。0.2.2 首次 CI 因测试里写死 Windows 绝对路径失败，改 `createRequire(new URL('../package.json', import.meta.url))` 后重跑成功。

## 六、踩过的坑

- **Windows 上不要把目录联接跨盘 `Move-Item`**：跨卷移动会退化成「跟随目标复制 + 删除源」，曾把仓库半搬进 `.trash` 并删掉源文件；恢复靠 `robocopy /E` 拷回 + `pnpm install --force`。清理联接只用 `Remove-Item <link>`（只删链接本身）。
- 明细页指标 tab 选中态只挂 `*On` 类、没挂基础类，露出浏览器默认按钮边框 —— 已修，并把「状态类必须与基础类同挂」做成检查规则。
- 概览趋势读 `usage.hoursByDate` 但服务端最初把该字段放在 heatmap 段，导致 7 天粒度永远回落按天 —— 契约统一到 `/usage` 后修复。

## 待办

按优先级（详细口径见 `docs/架构与数据契约.md` §3.23 与 `docs/UI规范.md`）：

1. **明细逐日表格的粒度**：分时范围下表格仍是按天一行，是否拆小时行需产品决定（G-07/G-20）；
2. **分布的项目 / 模型面板跟随范围与通道**：`projects` / `models` 段是全历史聚合，缺日期与通道成本维度，需要扩契约（G-12/G-23），并配统一的 `CostHint` 解释 `—`（G-13）；
3. **范围=今天时的「日均」语义**：日均 Tokens / 日均成本只有 1 天，是否改「时均」（G-18）；
4. **按时段错峰标记**：界面没有标出「错峰价」，均价偏低时看不出原因（G-22）；
5. **「今天」最后一格是滚动小时**：不足 1 小时，未在界面标注（G-26）；
6. 工具下钻（工具 → 会话列表）、提问词下钻（词 → 提问列表）需要的参数化端点（契约扩展）。
