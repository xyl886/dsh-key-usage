# v0.2.6（2026-11-02，已发布 2026-11-02）

## 界面与筛选

- 会话页「最近会话」默认隐藏已归档，列表 / 榜单 / 形态跟随顶部时间范围，「全部时间」开关移除；
- 工具栏新增「重置」按钮（范围 + 三个筛选一键复位，无筛选时置灰）；导出按钮去边框，与分页 / 重置统一。

## 移动端适配

- 断点 820 / 720 / 480 全部落在各模块 CSS 的 `@media` 块：不复制页面、不加移动版组件；
- 触控：`useTooltip` 支持 Mouse / Touch 两种事件（点按显示、再点关闭、点外部关闭），图表 / 热力图 / 会话成本格接线；`pointer: coarse` 下可点控件 ≥40px；
- 布局：工具栏换行、Tab 横向滚动、弹窗贴底、日历与筛选面板占满宽度、会话抽屉全屏、宽表横向滚动、年热力图横滚；
- 第二轮：设置弹窗竖排 Tab 改横排、时段矩阵横滚、筛选浮层锚点按视口收敛、明细排序 / 展开按钮 40px、日志列表 60vh、底部安全区；
- 第三轮：Mekko 与词云横滚、横滚容器 `overscroll-behavior-x: contain`、抽屉底部安全区、会话 / 额度触控目标；
- 第四轮：分页切 Tab 滚页面容器回顶（`[data-usage-scroll]`）、iOS 输入框 16px、分布 / 工具排行列宽收窄、锚点避开吸顶栏；
- 词典整理：`core/copy.ts` 的 zh/en 对象拆到 `core/locale/zh.json` / `en.json`（各 434 条），`copy.ts` 只做加载；`check:i18n` 改读 JSON 并检测重复键。
- 验证：每轮 `npm run verify` 全绿（22 个离线测试 + 8 道门禁）；未做浏览器实测（按 AGENTS 约定，截图与真机验证由用户完成）。
