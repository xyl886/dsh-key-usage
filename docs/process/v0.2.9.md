# v0.2.9（2026-11-21 发布）—— 全宽与紧凑留白 · 每轮费用 · 口径收敛

## 这一版做了什么

- **页面宽度铺满主区域**：去掉页头 / 工具栏 / 内容区三处 `max-width: 960px` 与页面容器 `max-width: 1240px` 的上限，统一由页面变量 `--ku-page-max` 控制（默认 `none` = 全宽，将来可一键收窄）；按时段热力格补 `max-height`，避免全宽后 7×24 矩阵被拉得过高。
- **留白收到 dsh-context 密度**：横向留白先由内部 24 + 区块 48 = 72px 收敛为单一 48px，再把横纵留白收到 12 / 10px（窄屏 10 / 8px），与宿主原生页一致。
- **每轮费用**：服务端新增 `GET /dsh-key-usage/turns?id=<sessionId>`，按轮聚合该会话的用量样本，价目 / 错峰 / 币种与页面完全同一套；客户端注册 `conversation.chat.assistant-actions` 插槽，把金额挂到对应回答的操作行**最末**（用量与耗时之后），每个会话只请求一次；没有价目依据显示 `—`，映射不上时整块不显示并记一条系统日志。
- **缓存命中率统一口径**：切片路径原先用 `input + cacheRead` 的比值（与其它路径量纲不一致），统一走 `cacheHitRateOf`（展示口径 tokens 为分母）。
- **导出补币种列**：逐日导出行增加币种列，混币种导出口径与页面一致。
- **数据覆盖时间线**：概览底部显示可查数据起止日期与「台账 N 天 / 会话补 N 天」；明细表 Tokens 列头补展示口径提示（缓存写参与计费但不计入展示口径）。
- **金额一律显示数值**：订阅制通道不再用「订阅内」占位，项目榜 / 模型榜解除金额抑制；KPI 成本卡去掉估算 / 官方账单等角标；未计价用量改用 `*` 标记；口径说明只保留在「设置 → 口径」。
- **开发流程**：desktop profile 只装真实包，验收改为装 dev 分支的提交（`git+file://`），不再用 `link:`；新增 [`docs/开发与验收流程.md`](../开发与验收流程.md)，dev 使用 `0.2.9-dev.N` 预发布号。

## 关键取舍

- **每轮费用按 messageId 对账，不依赖轮次编号**：宿主 turn ↔ message 的映射（`data.closing.finalNode` / `data.finalNode`）形状不稳定，快照里的轮次号不能当键；改用会话用量样本记下的宿主 `message.id`，对不上就宁可不显示（并记日志），不猜一条挂上去。
- **金额一律显示数值、不做文字占位**：页面要横向比较，「订阅内 / 无计费」这类文字不承载数字；口径说明集中到设置页，页面只留数字与未计价的 `*`。
- **未计价用 `*` 而不是把整行写成 `—`**：`*` 只标在「合计里含未计价 token」的金额上（合计偏小），逐行没有依据仍显示 `—`，避免把「无依据」当成 0。
- **全宽 + 紧凑留白对齐 dsh-context**：宿主页面本身没有内容列上限，插件再居中 960 会显得收窄；留白收到 12 / 10px 与宿主原生页同一密度，热力格用 `max-height` 兜住高度。
- **命中率以展示口径为准**：卡片 / 表格 / 导出三处统一按「输入 + 输出 + 缓存读」作分母；缓存写只参与计费、不进展示口径。

## 遗留

- 发布后 dev 上还有一批清理（提交 `4d34c8b`，随下一次发布）：服务端不再计算 / 下发订阅制估算标记（`subEstimate`），客户端类型与透传一并移除；清掉零调用的 `KpiStat.note` 与样式；`/turns` 会话缓存 6 → 24；AGENTS / README 的端点计数统一为 22 个路径。
- 每轮费用只覆盖对话区操作行；旧数据没有 `message.id` 时只能按快照轮次兜底，仍对不上就不显示（无从对账不猜）。
- 页面不再就地解释金额来源：理解「订阅制折算 / 带 `*` 的合计 / 无依据」需要到「设置 → 口径」看。
- 端点总数 22 = 19 个只读 `GET` + 4 个写 `POST`（`/log` 同时支持 GET 与 POST）；新增端点仍必须复用 `requireLoopback`。
